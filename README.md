# 📚 Library Management System

A web-based Library Management System that helps users manage books efficiently. It provides features to add, view, edit, search, delete, borrow, and return books.

## 🚀 Live Demo

**Frontend:** https://library-management-frontend-eta-three.vercel.app/

**Backend API:** https://library-management-api-fqdu.onrender.com/books

## ✨ Features

- Add new books
- View all books
- Edit book details
- Search books
- Delete books
- Borrow books
- Return books
- Dashboard statistics:
  - Total Books
  - Available Books
  - Borrowed Books
- Frontend and backend integration using REST API

## 🛠️ Technologies Used

**Frontend:**
- Next.js

- CSS

**Backend:**

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/lavanyadodda05-cmyk/library-management-frontend.git
```

### 2. Open the project folder

```bash
cd library-management-frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure the backend API

Create a `.env.local` file in the project root:

```env
NEXT_PUBLIC_API_URL=https://library-management-api-fqdu.onrender.com
```

### 5. Run the development server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
